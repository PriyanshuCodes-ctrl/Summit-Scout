Project overview

Explore smarter.

Summit Scout is a portfolio-ready route-planning concept that brings trek data, a 3D terrain explorer, personal estimates and a comparison tool into one dossier-style product.

Data driven

Route difficulty is computed from altitude, distance and the project's own planning indicators, across all 13 treks.

Explorable in 3D

A dedicated Three.js terrain view lets you rotate each route, inspect waypoints and fly to the summit marker.

Personalized

Profile inputs such as weight, height and fitness shape the project's calorie, BMI and trip-budget estimates.

Preparation focused

Dedicated route dossiers, a persistent gear checklist and a shortlist keep the important planning details close at hand.

Project stack

Built to demonstrate practical data & front-end skills

The wider Summit Scout concept can use Python for data processing and API integration, SQL or MongoDB for route and user data, and Power BI or Tableau for analytics on top of the same dataset.

Front endHTML, CSS, vanilla JS, Three.js for the 3D explorer
Data layerStructured trek dataset with 13 routes and waypoints
PersistenceShortlist, checklist progress and last plan via localStorage
